# dukemawex.github.io

Personal site for Emmanuel Effiom Duke — live at [duker.me](https://duker.me).

Single-file static site (`index.html`), served via GitHub Pages. No build step.
Sections: Projects, About, Experience, Education, Leadership, How I help,
Publications (from Google Scholar), Credentials, and Contact.

Photos live in [`assets/photos/`](assets/photos/README.md) — that README lists every
expected filename, its aspect ratio, and where it is used. Missing photos fall back
to labelled placeholders automatically.
